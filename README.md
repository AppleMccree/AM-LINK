# 课堂同传助手

推荐从 `D:\Codex\ClassInterpreter\dist\启动课堂同传.cmd` 启动。程序、运行时、录音、数据库、缓存和 Markdown 导出均位于 D 盘。

便携版会自动选择数据位置：D 盘可写时沿用 `D:\Codex\ClassInterpreter`；没有 D 盘时使用程序所在目录；程序目录不可写时使用 `%LOCALAPPDATA%\AM-LINK`。无需手动创建 D 盘。

首次使用：

1. 在阿里云百炼国际站创建新加坡地域 Workspace 和 API Key。
2. 打开应用，填写 Workspace ID 和 API Key，点击“安全保存 Key”。Key 只进入 Windows 凭据库。
3. 选择麦克风，可先录制 30 秒测试音频检查收音。
4. 在“翻译方向”中选择“英语/日语混合 → 中文”“中文 → 日语”或“中文 → 英语”。
5. 可导入 PPTX/PDF，填写课程名后点击“开始课堂”。运行期间方向会锁定，停止后可切换。
6. 再次点击停止；课后 Markdown 位于 `data\exports`。

如果暂时还没有 API Key，可先选择任意翻译方向，再点击“运行完整演示”。约数秒后可看到对应方向的原文和译文，并在 `data\exports\演示课堂` 生成真实 Markdown 学习包。

“英语/日语混合 → 中文”会启用 PPT 自动跟随；两个“中文 → 外语”模式只显示文字翻译并暂停 PPT 自动跳页，已导入课件不会丢失。软件不朗读译文。

原始录音默认保留 14 天，之后进入 24 小时可恢复删除区。字幕、SQLite 时间线和 Markdown 长期保留。

PPTX 会优先通过本机 PowerPoint 导出页面预览图；如果 Office 自动化在当前登录会话不可用，应用会自动回退到标题/正文文本预览，页码匹配和自动聚焦仍然可用。PDF 当前使用文本预览。
