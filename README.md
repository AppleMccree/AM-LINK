# AM-LINK

AM-LINK 是一款面向中文母语留学生的 Windows 课堂学习辅助工具。它把实时语音识别、日英中翻译、课件阅读、课堂问答和课后复习整理放在同一个应用中，帮助学生降低跨语言听课和交流的负担。

## 主要功能

- 日文、英文及日英混讲实时翻译为中文
- 中文与日文、中文与英文的双向同传
- 按课程和每节课保存字幕、课件、录音与学习记录
- 结合当前字幕和 PPT 内容进行课堂 AI 答疑
- 课后整理课堂摘要、重点知识、术语、作业与考试信息
- PPT 手动浏览、智能跳页提示和可选自动跟随
- 可选云端课堂问题板，支持匿名提问、点赞和教师端统计

## 运行与数据

应用为 Windows 桌面程序。发布版解压后可直接运行，数据目录会根据当前电脑的可写位置自动选择；没有 D 盘也能正常使用。

API Key 由使用者自行配置，并保存在 Windows 凭据管理器中。仓库不包含任何个人 API Key、课程、字幕、课件、录音、数据库或本地设置。

## 开发

项目使用 C#、.NET 8 和 WPF。解决方案入口为 `ClassInterpreter.sln`。

```powershell
dotnet restore ClassInterpreter.sln
dotnet build ClassInterpreter.sln -c Release
```
