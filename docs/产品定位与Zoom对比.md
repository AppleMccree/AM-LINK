# AM-LINK：不是另一个 Zoom 转录

Zoom 已经能提供会议转录、会议摘要模板、Lecture Summary 和会议内 AI 问答。AM-LINK 不以“Zoom 做不到转录”为卖点，而是解决个人学生在真实课堂里的学习问题。

## 两者服务的场景不同

| | Zoom | AM-LINK |
|---|---|---|
| 主要场景 | 已经在 Zoom 中进行的会议或网课 | 实体教室、讲座、任意麦克风音频 |
| 使用者 | 会议主持者与参会者 | 学生个人，不要求老师创建或管理会议 |
| 语言重点 | 通用会议转录 | 日文、英文、日英混讲到中文，并支持中日/中英临时双向翻译 |
| 课堂资料 | 会议内容为中心 | 课程→每节课→课件、双语字幕、问答、学习包 |
| 课件上下文 | 会议共享内容 | 学生自己的 PPT/PDF 当前页、相邻页与逐页文字 |
| 课后目标 | 回顾会议 | 形成可核查、可复习、带页码与时间戳的个人学习资料 |

## 一句话定位

AM-LINK 是面向留学生和多语言课堂的个人学习助手：不要求老师改变上课方式，把实体课堂的声音、学生手里的课件、即时疑问和课后复习资料连成一条完整学习链路。

## 对老师的回答

“Zoom 解决的是会议发生在 Zoom 里时的记录和协作；AM-LINK 解决的是学生坐在任意教室里，也能把日英混讲、自己的课件阅读位置、随时提问和课后复习资料组织起来。转录只是输入，真正的产品是学生可核查、可持续使用的学习过程。”
