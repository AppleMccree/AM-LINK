# 课堂同传与课件跟踪助手设计

## 目标

构建一款低占用的 Windows 桌面应用，通过笔记本或外接麦克风实时识别英语、日语及英日混说，尽可能低延迟地显示中文，并在课后生成可核查的 Markdown 学习包。应用可预导入 PPTX/PDF，并在自身界面中自动聚焦老师当前讲解的页面。

## 已确定的产品行为

- 平台：Windows 笔记本，C#/.NET 8 + WPF。
- 实时字幕：中文大字、英日原文小字；快速临时字幕目标 1–1.5 秒，稳定字幕目标 2–3 秒，只修订最近 1–2 行。
- 音频：麦克风采集、输入电平、降噪、语音活动检测；断网继续本地录音，恢复后补转录。
- 模型：默认使用阿里云百炼国际站。`qwen3-asr-flash-realtime` 识别，`qwen-mt-lite`（可切 `qwen-mt-flash`）翻译，`qwen-flash` 课后整理，`qwen3-vl-flash` 识别无文本课件页。DeepSeek V4 Flash 仅作为可选课后分析器；所有供应商均经过适配接口。
- 凭据：用户自行填写 API Key，使用 Windows Credential Manager 保存，不写入配置或数据库。
- PPT：本机提取 PPTX/PDF 文本、备注和缩略图；无法解析的页面允许逐页上传视觉模型。匹配仅使用稳定字幕和当前页邻近约束；低置信度保持当前页并显示最多 3 个候选。
- 课后：生成可搜索逐字稿、按 PPT 页摘要、知识点、行动项/截止日期、疑问和复习提纲；每项回链时间戳、原文与页码；仅导出 Markdown。
- 保留：原始音频默认保存 14 天，之后进入 24 小时可恢复删除区再彻底清除；文本、课件索引和 Markdown 长期保留。
- 存储：项目、程序、数据库、录音、缓存和导出默认全部位于 `D:\Codex\ClassInterpreter`，运行数据位于其 `data` 子目录。

## 架构与数据流

`AudioCapture` 输出 16 kHz 单声道 PCM 帧，同时写入分段录音和实时 ASR WebSocket。ASR 事件被标准化为含会话、起止时间、稳定状态、语言和置信度的 `TranscriptSegment`。`TranslationCoordinator` 对临时片段采用短上下文快速翻译，对最终片段结合术语表和最近上下文生成稳定中文。所有最终事件追加到 SQLite 时间线。

`SlideImporter` 将 PPTX/PDF 转成 `SlideDocument`、页面文本和缩略图；无文本页由视觉适配器补充描述。`SlideMatcher` 使用最近 20–45 秒稳定原文/译文、关键词相似度和页码转移惩罚给候选页评分。课后 `StudyPackGenerator` 从数据库按页面和主题分块，将结构化结果渲染成一个 Markdown 目录。

## 失败与恢复

- WebSocket 断开时指数退避重连；本地 WAV 分段始终优先写盘，恢复后建立补转录作业。
- 限流、余额不足和认证失败显示明确状态与本节估算费用，不丢录音。
- 低置信度识别保留原文并标记待核查，不把推测包装成确定译文。
- 每 5 秒提交数据库事务并原子更新会话状态；崩溃重启时恢复未完成会话。
- 清理任务只删除已超过保留期且未被用户锁定的音频，失败后重试并记录日志。

## 验收标准

- 真实网络下临时字幕首现中位数不高于 1.5 秒，稳定中文延迟 P95 不高于 3 秒。
- 连续运行两小时无崩溃、无持续增长的音频缓冲；断网 5 分钟后本地音频完整并能补转录。
- 含正常可提取文字的课件测试集中，当前页匹配准确率至少 90%，低置信度场景不自动跳页。
- 英日交替及同句混说样本需人工核对；若千问达不到可用标准，通过同一 ASR 接口接入 Deepgram Nova-3 multilingual，不修改 UI 或数据库。
- API Key 不出现在配置、数据库、日志、崩溃报告或导出的 Markdown 中。
