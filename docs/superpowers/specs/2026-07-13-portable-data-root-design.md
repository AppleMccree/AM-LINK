# AM-LINK 无 D 盘便携数据路径设计

## 目标

同一个 Windows x64 便携包同时支持当前有 D 盘的电脑和没有 D 盘的新电脑，不要求用户首次启动选择路径。

## 路径规则

1. 若 `D:\` 存在且 `D:\Codex\ClassInterpreter` 可创建、可写，沿用该目录，保留当前电脑的历史数据。
2. 否则使用 `ClassInterpreter.exe` 所在目录作为应用根目录，数据写入旁边的 `data` 与 `logs`。
3. 若程序目录不可写，退回 `%LOCALAPPDATA%\AM-LINK`。
4. 所有候选路径必须经过实际创建与写入探测；失败时继续尝试下一个候选，不因单个盘符缺失而闪退。

## 兼容与界面

- SQLite、录音、14 天清理、PDF 缓存、设置与 Markdown 导出统一使用解析后的根目录。
- API Key 仍仅存 Windows 凭据库，不写入便携目录。
- 当前 D 盘安装继续读取原数据；新电脑解压后无需 D 盘即可启动。
- 设置区显示实际数据路径。

## 验证

- 单元测试覆盖 D 盘可用、D 盘不存在、程序目录不可写三条路径。
- 完整测试、Release 构建、自包含发布和无 D 盘模拟启动均通过。
- 重新生成 ZIP，说明文件不再要求新电脑必须有 D 盘。
