# AM-LINK 黑金控制台 UI 设计

## 目标

将课堂同传助手的 macOS 玻璃界面替换为黑金设备控制台风格，但不复制任何第三方品牌名称或专用功能。产品名称统一为 `AM-LINK`，底部显示低视觉权重署名 `Developed by AppleMccree`。

## 信息架构

- 顶栏：`AM-LINK / CLASSROOM OS`、千问连接状态与窗口控制。
- 左栏：实时控制台、翻译方向、课堂课件、课后记录、连接设置；第一版仍在单窗口内工作，导航用于视觉分区和快速定位，不创建空白页面。
- 中栏：当前 PPT、目标语言大字幕、源语言原文、语言锁定状态、演示和课堂启动按钮。
- 右栏：`CHANNEL A` 麦克风输入、`CHANNEL B` 翻译输出、音量/缓冲/语言方向以及 ASR、PPT、录音、保留期状态。
- 底部：小号灰金色 `Developed by AppleMccree`。

## 视觉规范

- 背景使用近黑色，面板使用轻微层差，不使用玻璃模糊和 macOS 红黄绿按钮。
- 强调色为低饱和暗金；主按钮为金底黑字，次按钮使用金色虚线边框。
- 卡片使用 10–16 px 圆角、1 px 暗金描边；状态、波形、通道仪表采用设备控制台语言。
- 译文保持最高视觉层级，原文与诊断数据降低层级；所有输入框文字必须垂直居中且可读。
- 不使用 `DG-LAB`、`Coyote`、`郊狼` 等名称、图标或商标。

## 行为与兼容

- 不改变千问、双向翻译、录音、PPT 跟随、SQLite、Markdown、14 天保留或凭据存储逻辑。
- 左栏项目仅映射现有区域，不引入尚未实现的功能。
- A/B 通道是状态可视化：A 显示麦克风输入，B 显示翻译输出，不改变音频管线。
- 最小窗口仍为 940×640；控制区域允许滚动，实时字幕区域不得被遮挡。

## 验收

- 自动测试验证 AM-LINK 品牌、开发者署名、黑金主题资源与禁用品牌词。
- Release 构建 0 错误、0 警告。
- `--render-ui` 连续两次产生完整稳定截图；人工检查输入框、字幕、PPT、按钮和署名。
- 便携版覆盖后，从现有桌面快捷方式启动并保持运行至少 5 秒。
