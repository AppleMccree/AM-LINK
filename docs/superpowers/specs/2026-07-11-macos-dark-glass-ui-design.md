# macOS 深色玻璃界面设计

## 决策

- 保留现有左右双栏：左侧控制中心，右侧课堂实时区。
- 使用 macOS 深色玻璃风格，不增加第三方 UI 依赖。
- 自绘红黄绿标题栏，支持关闭、最小化、最大化、拖动和双击最大化。
- 统一 16–22 px 圆角、半透明卡片、细边框、柔和阴影和 iOS 蓝色主按钮。
- 实时译文保持最高视觉层级；原文、语言和帮助文字降低层级。
- 不改变翻译、录音、PPT、数据保留或凭据行为。

## 验收

- 940×640 最小窗口仍可操作，左侧允许滚动。
- 中文无乱码，输入、下拉框和按钮文字对比清晰。
- 无边框窗口可拖动、缩放并使用红黄绿控件。
- `--render-ui` 必须等待异步初始化后稳定生成完整截图。
