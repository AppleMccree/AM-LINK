# AM-LINK 课堂优先界面修订设计

## 问题结论

- 当前左栏模块是无事件的装饰元素，造成“可以点击”的错误暗示。
- PPT 区固定高度 145 px，不能承担课堂阅读。
- 右侧 A/B 信号架为静态装饰，占据关键宽度。
- PdfPig 仅提取 PDF 文字，无法展示页面画面。
- 英文诊断标签与大面积留白提高了课堂阅读成本。

## 新布局

- 顶栏只保留 `AM-LINK`、课程名、连接状态、`设置`、窗口按钮。
- 主体左侧占约 60%：大尺寸 PPT/PDF 页面，使用 `Uniform` 完整显示；上方显示中文页码与课件名，下方提供上一页/下一页及自动跟随状态。
- 主体右侧占约 40%：目标译文大字、源语言原文、语言状态；译文区域允许滚动但当前句始终突出。
- 底部放置“演示”和“开始课堂”，并保留小号 `Developed by AppleMccree`。
- 设置区改为右侧抽屉，默认收起；点击顶栏“设置”展开，包含翻译方向、麦克风、课程名、课件导入、百炼凭据和数据说明。
- 删除假导航、A/B 通道、16K、AUTO、DATA ROOT 和无功能英文状态架。
- 除 `AM-LINK`、API、PPT/PDF 和必要技术缩写外，界面文案使用中文。

## PDF 与 PPT 显示

- PPTX 继续优先使用 PowerPoint COM 导出页面 PNG；失败时保留文字降级。
- PDF 使用 `PDFtoImage 5.2.1`（PDFium + SkiaSharp）将每页渲染为 PNG，写入 D 盘缓存目录。
- PDF 渲染串行执行，避免 PDFium 非线程安全问题；导入期间显示中文进度。
- 页面图片缓存按源文件路径、修改时间和页码分目录，重复导入直接复用。
- 图片渲染失败时显示明确中文错误并保留 PdfPig 文字，不让整个导入失败。

## 交互

- 设置按钮真实开合抽屉；抽屉展开时不改变业务状态。
- 上一页/下一页按钮真实切换页面；自动跟随更新同一大图区域。
- 上课时设置抽屉自动收起，课件与字幕占满主体。
- 无课件时左侧显示大号导入提示，点击可触发课件选择。
- 现有双向翻译、录音、SQLite、Markdown、14 天保留和凭据存储不变。

## 验收

- 自动测试检查：无假导航/信号架英文、设置抽屉默认收起、主区 60/40、上一页/下一页按钮、PDF PNG 渲染与缓存。
- 使用用户提供的 12 页 PDF 验证第一页实际画面可见，而非仅文字。
- 1220×790 与 940×640 均无异常留白、裁切或遮挡。
- 完整测试、0 警告构建、连续截图、发布 DLL 哈希和 5 秒启动均通过。
